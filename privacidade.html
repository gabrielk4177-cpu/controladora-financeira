Política de Privacidade

Aplicativo: Controle Financeiro (Controladora Financeira Pro). Última atualização: 10 de novembro de 2026.

Quais dados o app usa

Os dados financeiros que o próprio usuário cadastra ou importa (lançamentos, categorias, contas, faturas, extratos). Eles ficam guardados no computador do usuário.

Uso dos dados do Google

  • Se o usuário conectar a conta Google, o app pede o endereço de e-mail (para mostrar qual conta está conectada) e a permissão drive.file, que dá acesso somente aos arquivos criados pelo próprio app.
  • O app cria no Drive do usuário a pasta “Controladora Financeira” com uma cópia dos dados, os extratos importados e cópias de segurança.
  • Os dados vão diretamente do computador do usuário para o Google Drive dele. Não existe servidor intermediário; o desenvolvedor não recebe, não vê e não armazena nenhum dado.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover

O usuário pode desconectar o Google Drive nas Configurações do app, revogar o acesso em myaccount.google.com/permissions e apagar a pasta “Controladora Financeira” do próprio Drive a qualquer momento.

Contato

Pelo e-mail de suporte exibido na tela de login do Google ou abrindo uma issue neste repositório.
